# ClipShare v0.1.0-beta.1 — Windows and Linux

ClipShare shares **text, files, and folders** between your computer and other devices on the same reachable local network. Everything stays on the computer hosting the session; no account or cloud service is required.

**This is a beta release.** Feedback and bug reports are welcome through [GitHub Issues](https://github.com/JackBauer69/clipshare/issues).

## Downloads

- **Windows 10/11 (64-bit):** `ClipShare-0.1.0-windows-x64-setup.exe` — guided installer for the current Windows user
- **Debian / Ubuntu / Kali (64-bit):** `clipshare_0.1.0_amd64.deb`
- **Fedora (64-bit):** `clipshare-0.1.0-1*.rpm` (the download will have an exact distribution suffix)
- **Integrity verification:** `SHA256SUMS` lists the checksum of every installer

macOS installers are **not included** in this release. Apple signing, notarization, and real-device validation will be handled separately.

## Quick start

1. Install and launch ClipShare on your Windows or Linux computer.
2. The browser opened by the desktop app signs in **automatically**.
3. On your phone or another computer connected to the same reachable LAN, visit the LAN address shown in ClipShare.
4. Enter the displayed **random four-digit pairing PIN** once for that browser.
5. Share text, files, or folders. Choose **Stop sharing** or **Quit** when finished; the temporary session data is deleted.

A phone browser may not support selecting entire folders; use individual file selection or a ZIP archive instead.

## Testing and limitations

- Linux `.deb` has been manually installed and real device-to-device sharing verified on Kali.
- Windows `.exe` has been manually installed in a Windows VM; the new quick-pairing workflow was checked by the project owner. CI also runs Windows install/self-test/uninstall smoke tests.
- Automated core tests and installer builds run across Windows, Linux, and two macOS architectures. The Windows and Linux installers are also package-smoke-tested in CI.
- The Windows installer may show a SmartScreen prompt if it is not signed. Confirm the download is from this repository's official GitHub Release.
- ClipShare uses **plain HTTP** and a convenient four-digit PIN; network traffic and codes are **not encrypted**. Use only on trusted local networks. This is not an Internet-facing file server.
- Installation and availability on every listed operating-system version have not been manually verified. Firewall rules and guest Wi-Fi isolation may prevent LAN access.
- The app is **not automatic clipboard sync**: sharing is initiated manually in the browser.
