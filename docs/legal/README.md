# ClipShare legal drafting workspace

These are **proposals for the owner and legal counsel to review**, not final legal terms:

- [Draft end-user license](DRAFT-END-USER-LICENSE.md): proposed free personal, educational, and internal business use of official binaries, while reserving redistribution and source-code derivative-product rights.
- [Draft commercial licensing policy](DRAFT-COMMERCIAL-LICENSING.md): possible permission process for selling products built using protected ClipShare code.

**Do not copy either draft to a root `LICENSE` file, embed it in an installer, or use it to satisfy CI release gates until the owner explicitly approves finalized terms following legal review.** The repository remains proprietary without a general public source-code license; see [LICENSING.md](../../LICENSING.md).

Outstanding inputs include the copyright owner's legal identity, approved contact information, governing law, actual warranty/limitation clauses, and how installation/acceptance will work on Windows, macOS, and Linux. RPM license metadata still contains a deliberately blocking placeholder, and macOS signing/notarization remains required.
